# لوحة الإدارة

تستخدم هذه النسخة واجهة GitHub الرسمية للنشر والرفع. لا تضع رمز وصول أو كلمة مرور في ملفات الموقع.

- المقالات: ملفات Markdown في `_posts/` وبالصيغة `YYYY-MM-DD-title.md`.
- `ads.txt` وملفات إثبات Google: تُرفع إلى جذر المستودع، مع الاحتفاظ بالاسم الذي توفره الخدمة.
- لا يوجد ملف `ads.txt` تجريبي حتى لا ننشر معرّف ناشر مختلق.
